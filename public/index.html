02

给机器人连接大脑

通过腾讯官方 CLI 完成账号授权，无需申请第三方应用。

点击连接，在打开的官方页面用与 WorkBuddy 相同的微信登录。官方 CLI 可能需要单独授权；仅打开 WorkBuddy 客户端不代表这里已连接。答疑关闭所有内置工具、MCP 和 Hook。

CLI 与 WorkBuddy 的可用模型及权益可能不同。默认开启「仅免费模型」，调用前核对官方目录中的 0 credits 标记；免费权益可能调整。关闭此选项后，测试和答疑可能消耗额度。

尚未授权打开官方授权页面 ↗
每次答疑前核对官方模型倍率；未标注免费时停止调用，不回退到收费模型。

登录凭据由官方 CLI 保存在本机独立配置目录，机器人页面不读取或显示令牌。账号登录完成后，先保存设置，再按需测试模型。

WorkBuddy 客户端的免费权益，不等于公开免费 API。

官方接入需要在开放平台创建并审核应用，再授权账号。官方任务接口未公开选择特定免费模型的参数，费用与额度以平台为准。若你已有 WorkBuddy 转接服务，请选「兼容 API」。
